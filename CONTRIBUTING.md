# Contributing to IT Project Management Toolkit

First off, thank you for considering contributing! It’s people like you that make this toolkit a great resource for the PM community.

## How Can I Contribute?

### Reporting Bugs
* Check the Issues tab to see if the bug has already been reported.
* If not, open a new issue with a clear title and a detailed description of the problem.

### Suggesting Enhancements
* We are always looking for new PM templates (Risk Logs, RACI matrices, etc.).
* Open an issue with the tag "enhancement" to discuss your idea.

## Pull Request Process
1. Fork the repo and create your branch from `main`.
2. If you've added a new template, ensure it follows the Markdown structure used in existing files.
3. Update the `README.md` with details of changes to the toolkit, if applicable.
4. Submit your PR with a brief description of what you’ve added or changed.

## Style Guide
* **Filenames:** Use lowercase and hyphens (e.g., `sprint-backlog-template.md`).
* **Headers:** Use standard Markdown `#` for titles and `##` for sections.
